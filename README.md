## 🔫 1. 枪械武器库与 1000 级强化突破

| 武器名称 | 定位与特色 | 核心机制 |
| :--- | :--- | :--- |
| **先锋电磁步枪** | 均衡输出 / 稳健点射 | 弹道平稳，开火节奏扎实稳健，初期开荒首选。 |
| **毁灭加特林风暴** | 超频暴射 / 金属风暴 | 高弹容量与高射速，大面积正面火力压制成群尸潮。 |
| **泰坦高斯穿甲狙** | 强力贯穿 / 极致高暴 | 单发超高毁伤重型轨道弹芯，直线贯穿整条道路敌人。 |
| **离子散射爆能枪** | 三路散射 / 广域覆盖 | 单次齐射 3 枚离子光束弹，大幅覆盖前方战区。 |

### 🛠️ 四大维度 1000 级阶梯强化机制
- **四大维度**：攻击力（Power）、射速（BulletSpeed）、攻速（AttackSpeed）、弹匣容量（MagazineCapacity）均支持突破至 **1000 级**。
- **阶梯式严苛消耗**：
  - **入门期（Lv. 1 ~ 5）**：仅需废料金币与少量基础碎片，**免除稀有核心要求**，新手体验丝滑顺畅。
  - **突破期（Lv. 6 ~ 1000）**：阶梯严苛递增金币与基础碎片，且**必须消耗【💎 稀有军工枪械核心】（rare_weapon_shard）**。
- **独占产出规则**：**稀有枪械核心仅限【精英模式】实战通关与精英扫荡必定掉落**，普通模式绝不产出！
- **数值安全边界与极速打击质感**：
  - 攻速设硬下限 `0.18s`（每秒最多约 5.5 发），彻底杜绝攻速超限鬼畜、音效重叠撕裂与每帧物理计算卡顿；
  - 弹速设硬上限 `2000`，避免过快导致单帧物理位移穿透怪物。

## 🗺️ 2. 五大递进战区 (50 关) 与极速扫荡体系

游戏设计了 5 大循序渐进的主题战区，共 50 个精心编排的防线关卡，外加终极无尽深渊：

```
[战区 1 · 废土边境] (关卡 1-10)   ──> 普通感染者与冲锋尸潮，初窥边境战区霸主
[战区 2 · 剧毒废墟] (关卡 11-20)  ──> 酸蚀突变体与极速冲锋者集群，化工厂毒沼
[战区 3 · 熔岩裂谷] (关卡 21-30)  ──> 地热通风塔与重装巨尸，决战炎魔领主
[战区 4 · 机械遗迹] (关卡 31-40)  ──> 赛博哨兵机甲与失控自动化兵工厂，电磁雷暴
[战区 5 · 虚空深渊] (关卡 41-50)  ──> 终极母巢母体与反物质断层，决战终末暴君
[终极战区 · 无尽深渊] (关卡 51+)  ──> 无极限防守极限模拟，检验指挥官终极科技
```

### 💀 双模式战斗体系
- **🌿 普通模式**：标准感染者破坏力与推进密度，用于稳步开荒与探索收集。
- **💀 极限精英战区**：感染者狂暴化（攻击力 +85%、生命 +85%、护盾 +60%、生成密度更高），享有 **200% 战利品掉落**，并且是**【稀有军工枪械核心】的唯一产出地**。

### ⚡ 已通关关卡极速扫荡（Sweep / Raid）
- **触发条件**：通关普通模式开启 **`⚡ 极速扫荡`**；通关精英模式开启 **`⚡ 精英扫荡`**。
- **瞬时结算**：消耗 5 ⚡ 作战能量，100% 瞬时结算该关卡全部物资（金币、定向技能芯片、基础碎片、指挥官经验）。
- **精英扫荡必出核心**：精英扫荡以高亮卡片必定结算【💎 稀有军工枪械核心】。
- **连续扫荡支持**：结算弹窗内置 **`⚡ 再扫一次`**，无需繁琐进退，畅快收割资源。

## 🛡️ 3. 怪物生命递增与高能装甲护盾系统（Shield）

为了避免高关卡敌人脆弱被秒杀，全面实装了**怪物血量与护盾分级机制**：

1. **生命值阶梯成长**：普通感染者基数提升至 75，重装巨尸提升至 580，首领 Boss 基础生命跃升至 **2400**，并随关卡数呈幂次增长。
2. **高能偏转装甲护盾**：
   - **Stage 1 ~ 3（教学期）**：0 护盾，顺畅上手；
   - **Stage 4 起**：怪物逐步装配等同于生命值 20%~40% 的装甲护盾；
   - **Stage 11 ~ 50**：中后期怪物护盾值达生命值的 45%~160%，Boss 更是标配巨额双层护盾；
   - **精英模式强化**：精英怪额外享有 **+60% 护盾加成**。
3. **视觉呈现与打击反馈**：
   - **双层血条**：怪物头顶显示**亮青蓝色能量护盾条**（上方）+ 鲜艳生命条（下方）；
   - **偏转力场环**：带盾敌人周身附带呼吸感青蓝电磁偏转力场光晕；
   - **护盾吸收与击碎**：受击优先由护盾吸收并溅射青蓝离子电弧，护盾被打空瞬间触发碎盾音效与 **`🛡️ 护盾击碎!`** 提示浮字！
   - **顶部 Boss HUD**：实时展示当前 Boss 的血量百分比与 `[🛡️ 护盾 数值]`。

## 🧩 4. 技能芯片收集与 Roguelike 构筑体系

游戏初始仅有枪械，所有技能必须通过在各战区中收集 **10 块专属战术芯片** 进行合成解锁：

### 🎯 战术技能体系
- 🚀 **温压火箭**：定点爆轰与大面积烈焰灼烧（火系）。
- 🚛 **重型装甲战车**：全道冲撞碾压沿途所有感染者，造成高额击退（物理）。
- ❄️ **极寒射线**：向前喷射大范围超低温冷气，减速并冻结敌人（冰系）。
- 🌀 **裂风涡流**：持续风暴涡流吸附聚怪，触发元素大范围扩散（风系）。
- 🪃 **回旋刃**：往返贯穿切割，自带 35% 额外暴击率（物理）。
- ⚡ **湮灭射线**：贯穿全屏的高能电磁激光，造成感电超载爆轰（雷系）。
- 🎯 **轨道轰炸**：战术红圈预瞄战区，连投 3 发烈火集束重弹（火系）。

### 💥 7 大元素化学反应协同
- 💥 **温差热力殉爆 (Thermal Shock)**：火箭或烈焰击中冰冻目标时，引爆 220% 超强热力殉爆与破甲蒸汽！
- ⚡ **电磁超导连锁 (Tesla Chain)**：主武器暴击时释放高压电弧，自动跳跃连锁打击周围敌人！
- 🌋 **雷火超载爆轰 (Overload)**：雷电攻击命中处于灼烧状态的敌人时，触发剧烈超载大爆炸！
- 🌪️ **裂风元素扩散 (Swirl Spread)**：涡流吸附敌人时，将其身上的灼烧或霜冻瞬间向全场扩散！
- 🛡️ **防线 EMP 脉冲环 (Fortress EMP)**：城防护盾破裂瞬间爆发全屏 EMP 冲击波，眩晕击退突入敌群！
- 🔥 **重装喷火战车 (Truck Inferno)**：装甲战车行进尾迹留下一整条炽热烈焰焦土！
- ❄️ **极寒深冻碎裂 (Cryo Shatter)**：战车碾碎冰冻敌人时向前方扇面爆射穿透冰晶尖刺！

## 🏰 5. 城防加固、伴飞战宠与远古符文工坊

- **四大城防科技**：复合装甲壁（生命）、能量屏障（护盾）、纳米自愈（回盾）、反伤尖刺（反伤）。
- **伴飞战术宠物**：
  - 🐱 **小毛球**：伴飞射出高能速射弹幕，并以小护盾吸收伤害；
  - 🐲 **烈焰幼龙**：扇面喷吐大范围高温龙炎吐息，附带灼烧火地。
- **远古符文工坊**：消耗符文碎片研磨永久被动符文（穿甲弹头、弱点标定、致命打击、弹道延程、分裂膛线等）。
- **体能与背包系统**：每次出击或扫荡消耗 5 点体能，背包实时管理枪械零件、芯片、基因与军备箱。

## 🛠️ 技术实现亮点

- **纯原生零依赖构建**：零 Webpack / Vite 强绑定依赖，纯 Canvas 2D + 现代标准 ES Module，极度轻量与高响应。
- **程序化音频引擎 (`SoundEngine`)**：利用浏览器 Web Audio API 动态合成枪声、装填、爆炸、激光与破盾音效，无需下载庞大音频文件。
- **全生命周期对象池 (`ObjectPool`)**：子弹、弹道、怪物、浮字文本、粒子特效 100% 池化复用，彻底消灭 GC 卡顿。
- **离屏 Canvas 预缓存**：重度滤镜、暗角与复杂粒子在离屏缓冲中预绘制，确保低配机型与移动端 60FPS 满帧运行。
- **数据持久化安全隔离**：`SaveManager` 支持深浅版本平滑迁移兼容与容灾默认值补齐。

## 📂 项目目录结构

```
kaipao/
├── assets/                 # 高精 UI 图标、技能卡面、宠物与战车透明精灵
├── config/                 # 技能与宠物配置清单
├── scripts/                # QA 语法测试脚本与资产生成工具
├── src/
│   ├── combat/             # 战斗系统、技能卡池 (SkillDeck) 与元素反应 (SynergySystem)
│   ├── core/               # 游戏主循环 (Game) 与核心设计参数配置 (Config)

│   ├── render/             # 高清 Canvas 渲染管线 (GameRenderer)
│   ├── systems/            # 关卡推进、出怪波次 (WaveSystem)、城防持久化 (SaveManager)、音效与震屏
│   ├── ui/                 # 现代化赛博大厅 (HomeLobbyUI)、战斗 HUD 与战利品结算
│   └── main.js             # 游戏启动与生命周期挂载入口
├── index.html              # 页面入口、移动端视口定义与高科技赛博加载屏
├── package.json            # 脚本定义与项目元数据
├── wrangler.jsonc          # Cloudflare Pages 自动化部署与自定义域名路由配置
└── README.md               # 游戏详尽说明文档
```
