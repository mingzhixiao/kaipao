### 🛠️ 四大维度 1000 级阶梯强化机制
- **四大维度**：攻击力（Power）、射速（BulletSpeed）、攻速（AttackSpeed）、弹匣容量（MagazineCapacity）均支持突破至 **1000 级**。
- **阶梯式严苛消耗**：
  - **入门期（Lv. 1 ~ 5）**：仅需废料金币与少量基础碎片，**免除稀有核心要求**，新手体验丝滑顺畅。
  - **突破期（Lv. 6 ~ 1000）**：阶梯严苛递增金币与基础碎片，且**必须消耗【💎 稀有军工枪械核心】（rare_weapon_shard）**。
- **独占产出规则**：**稀有枪械核心仅限【极限精英战区】实战通关与精英扫荡必定掉落**，常规防线绝不产出！
- **数值安全边界与极速打击质感**：
  - 攻速设硬下限 `0.18s`（每秒最多约 5.5 发），杜绝攻速超限鬼畜、音效撕裂与卡顿；
  - 弹速设硬上限 `2000`，避免过快导致单帧物理位移穿透碰撞体。

## 🗺️ 2. 五大递进星际战区 (50 关) 与极速扫荡体系

游戏设计了 5 大循序渐进的深空星际战区，共 50 个精心编排的要塞防线关卡，外加终极无尽战区：

```
[战区 1 · 星尘边缘] (关卡 1-10)   ──> 硅基噬矿兽与掠食冲锋群，决战轨道重装哨卫
[战区 2 · 强酸星环] (关卡 11-20)  ──> 酸雾卫星与腐蚀结晶管道，击溃强酸星环裂殖体
[战区 3 · 熔核裂隙] (关卡 21-30)  ──> 等离子通风塔与重装晶岩泰坦，迎战熔核等离子巨擘
[战区 4 · 智械废都] (关卡 31-40)  ──> 智械母舰与失控重巡装甲机，破解失控歼灭主脑
[战区 5 · 虚空母巢] (关卡 41-50)  ──> 星门裂隙折叠断层与暗能突触，终决虚空母巢支配者
[终极战区 · 无尽深空防线] (关卡 51+)──> 无极限深空生存防线，检验要塞指挥官终极科技
```

### 💀 双模式战斗体系
- **🌿 常规防线**：标准异兽破坏力与推进密度，用于稳步开荒与探索收集。
- **💀 极限精英战区**：异兽狂暴化（攻击力 +85%、生命 +85%、护盾 +60%、生成密度更高），享有 **200% 战利品掉落**，并且是**【稀有军工枪械核心】的唯一产出地**。

### ⚡ 已通关关卡极速扫荡（Sweep / Raid）
- **触发条件**：通关普通模式开启 **`⚡ 极速扫荡`**；通关精英模式开启 **`⚡ 精英扫荡`**。
- **瞬时结算**：消耗 5 ⚡ 作战能量，100% 瞬时结算该关卡全部物资（金币、定向技能芯片、基础碎片、指挥官经验）。
- **精英扫荡必出核心**：精英扫荡以高亮卡片必定结算【💎 稀有军工枪械核心】。
- **连续扫荡支持**：结算弹窗内置 **`⚡ 再扫一次`**，无需频繁进退。

   - **Stage 11 ~ 50**：中后期怪物护盾值达生命值的 45%~160%，Boss 更是标配巨额双层护盾；
   - **精英战区强化**：精英异兽额外享有 **+60% 护盾加成**。
3. **视觉呈现与打击反馈**：
   - **双层血条**：上方亮青蓝能量护盾条 + 下方鲜艳生命条；
   - **偏转力场环**：带盾敌人周身附带呼吸感青蓝电磁偏转力场光晕；

- 🌀 **微型引力奇点**：持续微型引力奇点牵引敌群，引发能量广域扩散（引力）。

## 🛠️ 技术架构亮点

- **纯原生零依赖构建**：纯 Canvas 2D + 现代标准 ES Module，极度轻量，极速冷启动。
- **程序化音频引擎 (`SoundEngine`)**：利用 Web Audio API 动态实时合成射击、装填、爆炸与破盾音效。
- **全生命周期对象池 (`ObjectPool`)**：子弹、敌对单位、宝石、浮字文本、粒子与命中环均由对象池 `get()/release()` 复用，并在回收时按 `active` 标记做 O(n) 原地紧凑化，避免频繁 `splice` 与短命对象堆积。
- **离屏 Canvas 背景层**：战场背景（地形、光效、装饰）预绘制到离屏 Canvas，按 `devicePixelRatio` 分配缓冲，每帧只做一次贴图，避免逐帧重绘静态图层；敌人接触阴影同样改为预烘焙贴图。
- **高 DPR 成本封顶**：`devicePixelRatio` 统一封顶到 2，并对同尺寸 resize 直接短路，避免移动端地址栏收放时反复重新分配整块画布。
- **数据持久化安全隔离**：`SaveManager` 支持向下迁移兼容，老用户数据无缝承接。
