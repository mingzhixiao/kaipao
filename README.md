# 末日塔防 Roguelike H5 (Kaipao Roguelike)

一款基于原生 HTML5 Canvas 2D + ES Module 模块化架构的末日废土塔防 Roguelike 动作网页游戏。

---

## 🎮 游戏核心玩法

- **防线坚守**：指挥官据守防线，自动/手动瞄准射击成群涌来的废土突变感染者。
- **三大战术技能体系**：
  - 🚀 **温压火箭**：定点爆轰与大面积烈焰灼烧。
  - 🚛 **重型装甲战车**：全道推进碾压尸潮，强力击退沿线敌人。
  - ❄️ **极寒射线**：大范围冰冻控场与霜冻减速。
- **元素化学反应与协同流派**：
  - 💥 **温差热力殉爆 (Thermal Shock)**：烈焰/火箭命中被极寒射线冰冻的敌人，引爆 220% 超强热差殉爆与群体破甲！
  - ⚡ **电磁超导连锁 (Tesla Chain)**：主武器暴击时释放高压电弧，连锁打击附近多个目标！
  - 🛡️ **紧急防线过载 (Fortress EMP)**：护盾被击破时瞬间爆发全场高能 EMP 电磁脉冲，冰冻并击退全场突入敌群！
  - 🔥 **重装喷火战车 (Truck Inferno)**：战车尾部加装火焰喷射，沿途留下一整条持久炽热焦土！
  - ❄️ **极寒深冻碎裂 (Cryo Shatter)**：战车碾碎冰冻敌人并向前方辐射爆射穿透冰晶尖刺！
- **Roguelike 战术升级**：击破敌人收集高能晶核，升级时动态抽取 3 选 1 战略卡片，打造独一无二的专属流派构筑。

---

## 🛠️ 技术架构与特性

- **纯原生零外部框架**：零打包门槛，基于原生 Canvas 2D 与现代浏览器 ES Module 构建。
- **纯程序化音频合成 (Web Audio API)**：内置 `SoundEngine`，无需依赖几十兆音频文件，通过高品质振荡器与白噪声实时拟真合成射击、命中、暴击、引擎轰鸣与爆炸声效。
- **高性能对象池 (ObjectPool)**：对子弹、怪物、粒子、飘字、光环等高频实体全量对象池管理，消除运行时 GC 停顿。
- **离屏 Canvas 预缓存**：重度滤镜与废土暗角预渲染至离屏缓冲，主循环毫秒级直接贴图，极大解放移动端与低端设备 CPU/GPU 压力。
- **多端触控与竖屏响应式适配**：支持 PC 鼠标精确微操与手机竖屏流畅滑动瞄准，内建安全区域 (Safe-area) 留白。

## 🚀 本地快速启动

```bash
# 启动本地轻量静态服务器
npm run dev

# 或使用任一静态服务器打开 index.html 即可游玩
```
默认在浏览器访问：`http://localhost:8099`

## 📂 目录结构

```
kaipao/
├── assets/             # 优化精简后的高清透明精灵与战略图标
├── src/
│   ├── combat/         # 升级卡池 (SkillDeck) 与元素反应协同系统 (SynergySystem)
│   ├── core/           # 核心逻辑主控 (Game) 与配置参数 (Config)
│   ├── render/         # Canvas 渲染器 (GameRenderer: 离屏缓冲与特效管线)
│   ├── systems/        # 资源管理器、对象池、程序化音效、打击感与屏幕震荡
│   ├── ui/             # HUD 界面交互与战术弹窗管理
│   └── main.js         # 游戏启动引导入口
├── index.html          # 游戏页面入口与高科技赛博加载屏
├── package.json        # 项目脚本与元数据
└── README.md           # 项目文档
```
